# Sesión 15 · Cierre de contenidos

El 25 de noviembre se desarrolla la última clase de contenido, de 6:00 a 10:00 p. m. La [guía docente](SESION_2026-11-25.md) organiza el ejercicio local de secretos y tres bloques de sistemas distribuidos: CAP y PACELC, bases de datos distribuidas y procesamiento de datos por lotes, rondas y eventos. Los productos de esta clase se usan en el [ejercicio colectivo del 2 de diciembre](../16_cierre/README.md).

## Materiales para la clase

- [Descargar las diapositivas en PowerPoint](Sistemas_distribuidos_CAP_datos_y_procesamiento.pptx). Los diagramas muestran cómo se pierde una actualización entre sedes, qué copias forman un cuórum, cómo se agrupan las claves en MapReduce y cuándo cambia un tablero al llegar un evento tardío.
- [Abrir el programa del ejercicio](ejercicio_configuracion/app.py). Desde la raíz del repositorio, sigan los comandos de la [guía de la sesión](SESION_2026-11-25.md). Para la apertura se usan Bash, Git y Python 3.
- [Consultar el módulo de sistemas distribuidos](../../../modules/05_distribucion/README.md) para revisar cómo se comunican las réplicas y dónde se conserva el estado.
