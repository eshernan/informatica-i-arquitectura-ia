# Contribuir

1. Cree una rama corta desde `main`.
2. Explique el problema, la decisión y la evidencia de validación.
3. Ejecute `make check` y `make test`.
4. No confirme secretos, datos personales, modelos ni imágenes de contenedor.
5. Actualice el README del módulo cuando cambien instalación, contrato o ejercicio.
6. Declare asistencia de IA relevante en la solicitud de cambio.

Una contribución arquitectónica significativa debe incluir o actualizar un ADR. Los hallazgos de seguridad no se publican en una incidencia abierta; siga [SECURITY.md](SECURITY.md).
